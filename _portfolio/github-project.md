In Applied Mathematics, we encounter many real world problem and working professional in the industry, hires mathematicians to understand their real world problem and apply their mathematical modeling skills to model it as a mathematical problem that can be solvable by rich collection of mathematical methods. But as Artificial Intelligence envolved, researcher find that mathematician needed to perform the simulation to provide the solution to these modeled mathematical problem using the mathematical methods. In this process they actually generate alots of the data during simulation of the system that they have modeled. Data is the core of the current existing industrial problems and researcher thought that if we able to build a system that have capability to actually perform that simulation of the complex systems. Hence, rise of the mathematical data driven methods started from here.
